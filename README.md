Microsoft Enterprise Endpoint Management & Windows Security Lab

This project is a hands-on enterprise IT support lab focused on managing and securing Windows endpoints in a Microsoft-based environment. It demonstrates practical skills in Windows workstation configuration, Microsoft Intune fundamentals, device and user management, BitLocker, Windows Update, endpoint security, networking, and troubleshooting.

The project also follows a structured IT support process: identifying issues, investigating possible causes, applying solutions, testing the results, and documenting the work with screenshots and technical notes.

Main areas covered:

Windows 10/11 workstation setup and configuration
Microsoft Intune and endpoint management fundamentals
User, device, and access-management basics
BitLocker and Windows security configuration
Windows Update and system maintenance
TCP/IP, DNS, and network connectivity troubleshooting
Windows command-line troubleshooting
IT support documentation and troubleshooting reports
