# Microsoft Enterprise Endpoint, Identity & Windows Security Lab

Hands-on enterprise IT support lab focused on Microsoft Entra ID, Intune, Windows endpoint management, security, networking, troubleshooting, and technical documentation.

## Project Overview

This project is designed to build practical skills for enterprise IT support, endpoint management, and Microsoft cloud administration roles.

Main areas covered:

- Microsoft Entra ID
- Microsoft Intune
- User and group management
- Windows 10/11 endpoint configuration
- Device management
- Identity and access management fundamentals
- BitLocker and Windows security
- Windows Update
- Network and DNS troubleshooting
- Technical documentation

## Practical Tasks

- Created and managed users and groups in Microsoft Entra ID
