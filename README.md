# Microsoft Enterprise Endpoint Management & Windows Security Lab

Hands-on IT support lab focused on Windows endpoint management, Microsoft Intune fundamentals, Windows security, networking, troubleshooting, and technical documentation.

## Project Overview

This project is designed to build practical skills for enterprise IT support and endpoint management roles.

Main areas covered:

- Windows 10/11 configuration
- Microsoft Intune fundamentals
- User and device management
- BitLocker and Windows security
- Windows Update
- Network and DNS troubleshooting
- Command-line troubleshooting
- Technical documentation

## Practical Tasks

- Configured Windows workstations and user accounts
- Practiced endpoint and device management
- Configured BitLocker and basic security settings
- Troubleshot internet, DNS, and connectivity issues
- Used tools such as `ping`, `ipconfig`, and `nslookup`
- Practiced Windows Update and system maintenance
- Documented troubleshooting steps with screenshots
